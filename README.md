# کنترل ۸ رله STM32 با رابط HTML

رابط وب زیبا برای کنترل ۸ رله متصل به STM32F4 Discovery از طریق USB-Serial.

## ویژگی‌ها

- کنترل دستی هر رله (Toggle)
- حالت اتوماتیک با سکانس رقص نور
- رنگین‌کمان دایره‌ای کامل (هر رله یک حلقه رنگی)
- طراحی راست‌چین و مناسب موبایل

## نحوه استفاده

1. فایل `index.html` را با Chrome یا Edge باز کنید
2. به پورت سریال USB-TTL متصل شوید (باودریت ۹۶۰۰)
3. رله‌ها را کنترل کنید

## اتصالات

- TX تبدیل → PA10
- RX تبدیل → PA9
- GND مشترک
